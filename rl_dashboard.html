Runs

Every run starts from the same pretrained weights (400k-step EMA) and the same optimiser settings; only the sampler and the update rule differ. GPU-hours is CUDA-synchronised train time (rollout + decode/reward + update); evaluation is off the clock. Rollout kB is measured on the training sampler (SDE for Flow-GRPO, ODE for DGPO); eval kB on the deployment sampler (20-step ODE, CFG 4) over all 45 prompts, so eval is what a user of the weights would get.
